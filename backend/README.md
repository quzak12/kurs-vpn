# KURS VPN — backend (первый этап)

Backend проверяет данные входа Telegram Mini App и создаёт отдельную запись для каждого Telegram ID. Подписка новых пользователей не активна. Оплата, VPN-сервер, выпуск ключей и автоматическое включение/выключение доступа пока не реализованы.

## Что понадобится для запуска

- Node.js 24 LTS.
- Постоянно работающий хостинг с HTTPS и постоянным диском для SQLite. GitHub Pages не запускает backend; на бесплатных платформах проверьте, сохраняется ли база после перезапуска.
- Переменные окружения, задаваемые в настройках хостинга:
  - `BOT_TOKEN` — секретный токен бота из BotFather. Никогда не размещайте его в репозитории, HTML или логах.
  - `FRONTEND_ORIGIN` — origin сайта, например `https://quzak12.github.io` (без завершающего слеша и пути).
  - `PORT` — порт сервера; по умолчанию `3000`.
  - `DB_PATH` — путь к файлу SQLite на постоянном диске; по умолчанию `./kurs-vpn.db`.

Команда запуска из папки `backend`: `node server.js`. В Node.js 24 встроенная SQLite может выводить предупреждение об экспериментальном модуле.

`GET /health` возвращает состояние сервера. `POST /api/me` принимает JSON вида `{ "initData": "..." }`, проверяет подпись и возраст данных, создаёт пользователя и возвращает его статус. Клиент должен отправлять исходную `Telegram.WebApp.initData` только по HTTPS. При запуске Mini App из некоторых типов кнопок данные могут отсутствовать; используйте способ запуска, поддерживающий initData. Не записывайте initData в логи или публичную базу.

## До запуска для реальных клиентов

Настройте HTTPS, резервное копирование постоянной базы, ограничение частоты запросов, мониторинг и защиту хостинга. Перед коммерческим использованием отдельно разработайте безопасную обработку платежей и отзыв VPN-доступа, а также проверьте юридические требования и политику конфиденциальности. Этот код не активирует подписки и не защищает переданную пользователем другому человеку VPN-ссылку.
