# KURS VPN: Cloudflare Workers + D1

Этот вариант предназначен для бесплатного уровня Cloudflare Workers и базы D1. Он не запускает VPN, не принимает оплату и не выдаёт ключи. Перед использованием в работе с платными клиентами нужно дополнить безопасность, мониторинг, резервное копирование и проверить юридические требования.

## Что потребуется для развёртывания

1. Аккаунт Cloudflare с доступом к Workers и D1; выбрать Free, не платный план.
2. Создать D1-базу и выполнить в ней `schema.sql`.
3. Развернуть `worker.mjs` как Worker, привязать базу как `DB`.
4. Указать `FRONTEND_ORIGIN` как публичный origin сайта (например, `https://quzak12.github.io`, без пути и завершающего `/`).
5. Сохранить токен Telegram-бота в секрет Worker с именем `BOT_TOKEN`, не в репозитории и не в чате.
6. Проверить `https://АДРЕС-WORKER/health`, затем указать публичный HTTPS-origin Worker в `config.js` сайта. После этого вход надо проверить из Telegram двумя разными аккаунтами.

Все данные из `initData` проверяются по подписи на сервере. Ответ `/api/me` содержит только запись проверенного Telegram ID. Система платежей и активация подписки пока не реализованы.

Не вводите настоящий токен в публичный код, GitHub, скриншоты или чат. Бесплатные квоты, доступность из РФ и условия могут меняться: проверяйте их у Cloudflare перед запуском. При исчерпании бесплатного лимита запросы могут перестать выполняться.
